# Artifice Site v2

Static immersive concept site for Artifice.

## Deploy on Vercel

- Framework preset: `Other`
- Root directory: this folder
- Build command: leave empty
- Output directory: leave empty

Vercel should serve `index.html` directly.

## Files

- `index.html`
- `styles.css`
- `script.js`
- `vercel.json`

## Notes

- This is separate from `Artifice Booking Site` (`v1`).
- Current preview is static and does not require Node to run on Vercel.
